NetSwitcher v3 —— 手机热点切换 + 内网识别 + 出口选择
==========================================================

【说明】本文件是开发笔记。面向用户的完整文档请见 README.md。
        编译请用 build.bat；外网探测点可用 probe.example.txt 配置。

【两个核心改动】
1. 不猜具体机型。
   手机热点那一栏完全实时扫描：附近扫得到的、系统里存过的、
   你手动固定过的，全列出来。名字像手机的标 🍎 / 🤖，不像的用 📶。
   安卓/苹果手机开热点后，几秒内它自己就会出现，点一下就连。

2. 内网识别做成了可视化卡片，而且能设置走哪条路。
   每块带网关的网卡一张卡片，绿色灯 = 网关有回应。
   卡片底部用 🔒 标出「走这块网卡的专线网段」。
   例如：有线网卡挂了 10.0.0.0/8 的内网专线，Wi-Fi 是默认出口，
   那就是上网走 Wi-Fi、内网走有线，两者同时生效。

【界面怎么读】
顶栏
  当前出口              <- 系统默认走哪块网卡（问内核要的，不是猜的）
  Wi-Fi                 <- 现在连的哪个热点

手机热点（每张卡片）
  「使用中」= 正连着
  「可切换」= 扫得到，点一下就切过去
  「离线」  = 存过但现在扫不到
  「首次连接要密码」= 系统里没存过，点它会让你输一次，之后记住

内网 / 有线（每张卡片）
  左上绿点  = 网关有回应
  右侧小字  = 靠什么确认的：ping / ARP / TCP80
  「默认出口」= 系统当前从这里出网
  「内网」    = 它上面挂着内网专线（底部 🔒 那个网段）
  「备用」    = 通，但既不出口也没专线

【操作】
· 左键热点卡片    -> 切过去（连接）
· 右键任意卡片    -> 自绘圆角菜单（两类卡片统一都是右键打开选项）：
                      热点卡：复制 SSID / 连接 / 断开 / 添加备注 / 固定 / 手动输入
                      内网卡：取消内网固定 / 固定内网网段 / 所有上网流量改走这块网卡 /
                              恢复系统自动选择出口 / 添加备注 / 复制 IP / Ping 网关 / 详情
· 左键内网卡片    -> 不触发动作（设置统一走右键）
· 拖动标题区域    -> 移动面板
· Ctrl+Alt+N      -> 呼出/收起
· F5              -> 立即重新检测
· Esc             -> 收起
· 关窗口          -> 只收进托盘，不退出
· 再双击 exe      -> 把已经开着的面板叫到前面来

【两种「选网络」到底差在哪】
固定内网网段（推荐）
  只给这个网段加一条静态路由指向该网卡的网关。
  上网继续走原来的默认出口，内网走这条线，互不干扰。
  这正是你现在生效的状态。

所有上网流量改走它
  把这块网卡的接口度量调到 1，其他调到 60，
  于是全部出网流量都从它走。只在"整机要换到另一条线"时用。

两个都要改系统设置，所以会弹 UAC；拒绝也没关系，只是不生效。

【配置在哪】
%APPDATA%\NetSwitcher\
  slots.txt  你手动固定住的热点（每行一个 SSID）
  ui.txt     面板位置
  pref.txt   你指定的优先出口网卡名（空 = 自动）
  notes.txt  你给网络起的备注（键<TAB>备注，键是 wifi:SSID / lan:网卡名）

【2026-11-11 三处改动】
1. 卡片上的鼠标光标改回系统默认箭头。
   之前卡片设了 Cursors.Hand（手形），那是网页里的东西；Windows
   自己的列表项、按钮都是箭头，摆在一起就不像桌面程序。现在热点卡、
   内网卡、右上角四个圆按钮全部跟随系统光标。

2. 点卡片弹出的菜单重做了（原来是系统的 ContextMenuStrip）。
   系统菜单是直角窗、行高 22、分隔线通栏、悬停一条生硬灰底，
   跟这套「白卡 + 12 圆角 + 极淡影」摆在一起像两个时代的东西；
   只改 ProfessionalColorTable 能换颜色，改不了那套几何。
   现在是自绘的 FlatMenu：12 圆角、38 行高、左侧系统字形图标、
   悬停淡蓝胶囊、主操作用主蓝加粗、次要信息（网段 / IP / 状态）放右侧
   浅灰小字。键盘 ↑↓ Enter Esc、点菜单外自动收起、超出屏幕自动翻转，
   都按系统菜单的行为补齐了。

3. 新增「备注」：右键任一卡片 -> 添加 / 修改备注，给网络起自己的名字。
   备注直接显示在卡片上（热点卡在左下角，内网卡在网卡名右侧），
   都是淡蓝小胶囊 + 便签图标，一眼认出是哪个网。
   保存时留空 = 删除备注，改完立刻刷新，不用重新扫描。

【2026-11-10 修的两个真问题】
1. 右上角四个键的图标是两套混的。
   关掉的叉原来用 E8BB(Cancel)，这字形自带一个实心圆盘，
   压在按钮的半透明圆底上就像「实心徽章」；
   刷新和齿轮却是纯线条，摆在一起明显不是一套。
   现在叉换成 E711(Clear)（纯描边），按钮底改成
   只有鼠标压上去才浮出来，平时就是四枚干净的线条图标。
   各字形墨迹大小不同，缩放比也各自调过，视觉上一样大。

2. 「取消内网固定」点了没反应。三个原因叠在一起：
   · 显示的网段是错的。菜单取的是网卡自己的直连网段
     （网卡自己的直连网段），真正固定着的是另一条内网专线网段。
     点下去删的是另一条路由，当然没反应。
   · 判断依据是错的。原来靠读注册表 PersistentRoutes 键判断
     「有没有固定过」，但 netsh 写的持久路由在 Win10/11 上
     根本不落进那个键，于是永远判定「没固定」，
     点「取消」反而又去添加一遍。
   · netsh 语法也不对。正确的是
       netsh interface ipv4 delete route prefix=网段 nexthop=网关 interface=网卡
     少写 prefix= / interface= 会直接报「语法无效」。
   现在改成：用 netsh 读真实持久路由（按列位置解析，不看界面语言），
   菜单列的是真实存在的那条，动作由主进程明确指定 add 还是 delete，
   加完删完都回读校验。

【重新编译】
方式一：双击 build.bat（自动找 csc.exe，推荐）
方式二：命令行
  C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe ^
    /target:winexe /optimize+ /win32icon:app.ico /win32manifest:app.manifest ^
    /out:NetSwitcher.exe NetSwitcher.cs AssemblyInfo.cs

【已知限制】
· 手机热点名改过之后，旧卡片显示「离线」，需要扫到新名字再点它。
· 不少机器禁了 ICMP，所以「有没有回应」会退到 ARP / TCP，
  卡片上会写明是靠哪种方式判断的，不会瞎说通或者不通。
· 切换靠 netsh wlan connect，实测 3~10 秒；手机热点那边不能关。
· 「能否上外网」是绑源地址实测的，只对非默认出口的网卡做，避免拖慢刷新。
